## 🚀 Getting Started

Follow these instructions to run a local instance of the application on your development machine.

### Prerequisites

Ensure you have the following installed:
- **Node.js** (v18.0.0 or higher recommended) — [Download Node.js](https://nodejs.org/)
- **npm** (bundled with Node.js) or **yarn** / **pnpm**

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/dhananjaysable/Abaxacademy.git
   cd Abaxacademy
   ```

2. **Install project dependencies:**
   ```bash
   npm install
   ```

### Available Scripts

In the project root, you can execute:

| Command | Action |
| :--- | :--- |
| `npm run dev` | Starts the Vite local development server at `http://localhost:5173/Abaxacademy/` |
| `npm run build` | Compiles the production-ready bundle into the `dist/` directory |
| `npm run preview` | Locally serves the production build from `dist/` for verification |
| `npm run lint` | Runs ESLint to check for code syntax and styling issues |
| `npm run deploy` | Builds the project and automatically deploys the output to GitHub Pages |

---

## 🚢 Deployment Guide

The project is configured for automated deployment to **GitHub Pages**.

1. Ensure the `base` path in `vite.config.js` aligns with your repository name:
   ```javascript
   export default defineConfig({
     plugins: [tailwindcss(), react()],
     base: '/Abaxacademy/'
   })
   ```
2. Trigger the automated build and deployment script:
   ```bash
   npm run deploy
   ```
   *(This script will build the application via `npm run build` and push the `dist` directory to the `gh-pages` branch).*
