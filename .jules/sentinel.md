## 2025-02-28 - Unhandled Forms and Unrestricted Iframes
**Vulnerability:** Forms lacking `e.preventDefault()` on submission leading to unintended GET requests leaking PII (Name, Email, Phone Number) into URL parameters. Additionally, third-party iframes (like Google Maps) were completely unrestricted.
**Learning:** In this React architecture, static forms often rely on default HTML behavior which defaults to a GET submission, unintentionally leaking sensitive user inputs in URLs. This pattern is easy to overlook in static or UI-only forms. Additionally, embedding external maps without `sandbox` attributes exposes the site to broader attack surfaces from third parties.
**Prevention:** Always explicitly add `onSubmit={(e) => e.preventDefault()}` to static or UI-only React forms unless actively handling submissions via POST/API. Additionally, always apply `sandbox="allow-scripts allow-same-origin allow-popups"` to external `<iframe>` embeds to restrict potential third-party script execution.
