## 2025-03-05 - Default Form Submission PII Leakage Risk
**Vulnerability:** Registration form lacks an `onSubmit` handler with `e.preventDefault()`, which causes the form to execute a default GET request upon submission, potentially exposing sensitive Personally Identifiable Information (PII) like names, emails, and mobile numbers in the URL query string.
**Learning:** React components often utilize unmanaged or visually-managed forms relying on default HTML behavior. In a SPA without a designated action, a form submission defaults to a GET request to the current URL, unintentionally appending all named inputs (or generating empty keys) as URL parameters, leaking data to browser history, server logs, or third-party tracking scripts.
**Prevention:** Always implement an explicit `onSubmit={(e) => e.preventDefault()}` handler on React forms before implementing asynchronous submission logic, preventing accidental default submissions that could leak PII in URL parameters.
