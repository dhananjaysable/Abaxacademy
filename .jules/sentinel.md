## 2024-05-18 - Missing Form Prevent Default Leading to PII Leakage
**Vulnerability:** A standard React HTML `<form>` was implemented without an `onSubmit` handler to call `e.preventDefault()`. As a result, clicking the submit button triggered the default browser form submission behavior. This caused the form to reload the page and append form input values (such as Name, Email, Mobile No) as URL query parameters in a GET request.
**Learning:** Default form submissions in React single-page applications bypass the intended client-side state management and inherently default to GET requests. This causes any inputted data to be exposed directly in the URL, which is a major security concern for forms collecting Personally Identifiable Information (PII) like names and phone numbers.
**Prevention:** Always attach an `onSubmit` handler to any `<form>` element in a React component and explicitly call `e.preventDefault()` within it. Additionally, ensure form inputs are properly managed via state or refs, and any API submissions are handled securely through asynchronous POST/PUT requests using `fetch` or a similar library, rather than relying on default form actions.
