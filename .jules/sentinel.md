## 2024-05-24 - [PII Leakage in React Registration Form]
**Vulnerability:** Registration form lacks `onSubmit` handler to prevent default behavior, causing user PII (Name, Email, Mobile No, etc.) to be inadvertently leaked in the URL query string via a default GET request when submitted. Additionally, missing client-side validation allows malformed input.
**Learning:** In React single-page applications, forms without an explicit `e.preventDefault()` in their `onSubmit` handler will trigger traditional browser form submission (defaulting to GET if no method is specified), exposing all input values in the URL parameters. This is a critical privacy concern for forms collecting sensitive personal information.
**Prevention:** Always implement an `onSubmit` handler on `<form>` elements in React with `e.preventDefault()` to intercept submission and handle data securely (e.g., via controlled state and API POST requests). Additionally, utilize HTML5 validation attributes (`required`, `type="tel"`, `pattern`, `maxLength`) to enforce client-side constraints before submission logic is executed.
