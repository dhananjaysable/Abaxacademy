## 2024-05-29 - [Prevent PII Leakage via Default Form Submission]
**Vulnerability:** Registration forms in React components were missing `e.preventDefault()` on submission, leading to default browser behavior that submits the form via a GET request. This appends all input values (including PII like names, emails, and phone numbers) directly into the URL parameters.
**Learning:** In a single-page React application, omitting an explicit submit handler does not just result in a no-op; it falls back to native HTML form submission. If the form lacks a `method="POST"` attribute (which requires a backend endpoint), it defaults to GET, resulting in potentially severe PII leakage into browser history, server logs, and proxies.
**Prevention:** Always add an `onSubmit` handler to `<form>` elements in React that at minimum calls `e.preventDefault()`, even if the form is currently non-functional or just a UI placeholder. Also ensure inputs for sensitive data are handled via controlled components and submitted securely (e.g., via POST to a secure API) rather than relying on default form behaviors.
