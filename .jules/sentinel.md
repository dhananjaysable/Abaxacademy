## 2026-05-06 - [PII Leakage in Form Submissions & Insecure Embeds]
**Vulnerability:** Registration form lacks `e.preventDefault()`, causing default GET submissions that leak Personally Identifiable Information (PII) like name and email in URL parameters. Additionally, third-party map embeds lack `sandbox` attributes, exposing the app to potential unauthorized capabilities.
**Learning:** Default form behaviors in React without `onSubmit` handlers inherently perform GET requests appending input data to the URL. Relying purely on visual layout without functional handlers creates a data leakage risk. Third-party embeds like Google Maps require explicit capability restriction via `sandbox` to align with defense-in-depth principles.
**Prevention:** Always implement `onSubmit={(e) => e.preventDefault()}` on React forms, even if they are currently just placeholders, to prevent unintended data exposure. Always apply `sandbox="allow-scripts allow-same-origin allow-popups"` to third-party `<iframe>` embeds to enforce capability boundaries.
