## 2025-05-18 - Prevent PII leakage in React forms and harden third-party embeds
**Vulnerability:** Registration forms without `e.preventDefault()` leak Personally Identifiable Information (PII) like names, emails, and phone numbers in URL parameters via default GET submissions. Additionally, third-party iframes (like Google Maps) lacked security boundaries, exposing the site to potential cross-site scripting (XSS) or top-level navigation hijacking if the third party is compromised.
**Learning:** In React applications built with Vite/Tailwind, standard `<form>` elements must explicitly handle submissions to override default browser behavior. Unsecured embeds inherently expand the attack surface, trusting third-party domains completely.
**Prevention:** Always implement `onSubmit` handlers with `e.preventDefault()` for React forms. Consistently apply `sandbox="allow-scripts allow-same-origin allow-popups"` to external `<iframe>` elements to strictly define permitted behaviors while preserving necessary functionality.
