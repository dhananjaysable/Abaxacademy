## 2026-05-24 - [Unintended PII Leakage via Default Form Submission]
**Vulnerability:** Registration forms in React components lacked an `onSubmit` handler with `e.preventDefault()`. Since the forms contained `<button type="submit">` and no `method` was specified, submission defaulted to an HTTP GET request, appending all form input values (like names, emails, mobile numbers) directly to the URL parameters.
**Learning:** In Single Page Applications (SPAs) built with React, forms without explicit submission handlers still trigger standard browser behavior. This can unintentionally leak sensitive Personally Identifiable Information (PII) into browser history, server logs, and referrer headers if the default submission action is not intercepted.
**Prevention:** Always attach an `onSubmit` event handler to `<form>` elements and immediately invoke `e.preventDefault()` to stop the default browser behavior, ensuring form data is handled securely within the client-side state or via appropriate asynchronous POST requests.
