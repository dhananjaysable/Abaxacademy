## 2024-05-05 - Default Form Submission PII Leak
**Vulnerability:** React forms without explicit `e.preventDefault()` in their `onSubmit` handler will perform a default GET request when submitted, appending all input values to the URL parameters. This inadvertently leaks sensitive user data (PII) like names, emails, and phone numbers into browser history, server logs, and potentially third-party analytics scripts.
**Learning:** In a single-page application (SPA), forms are typically handled by JavaScript, and the default browser submission behavior is almost always unintended. Relying on default button behavior (`type="submit"`) without an explicit `onSubmit` handler at the `<form>` level is a common oversight that leads to this vulnerability.
**Prevention:** Always implement an `onSubmit` handler on the `<form>` element itself (not just `onClick` on the submit button) and ensure `e.preventDefault()` is the very first statement executed to block the default GET submission behavior.
