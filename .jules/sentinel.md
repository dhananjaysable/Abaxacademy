## 2024-07-02 - PII Leakage via Default Form Submission
**Vulnerability:** The registration form in `src/components/DirectionsRegistration.jsx` lacked an `onSubmit` handler to prevent the default form submission behavior. This could cause the browser to submit a GET request with all form field values, including PII like name, email, and mobile number, directly in the URL parameters.
**Learning:** Default HTML form behavior in React applications without `e.preventDefault()` can inadvertently leak sensitive user information into server logs, browser history, and referrer headers if the form submission happens via GET. This is especially risky when forms do not have explicitly defined `action` or `method` attributes.
**Prevention:** Always implement an `onSubmit` handler with `e.preventDefault()` for all forms in React, even if they are only visually implemented initially. When implementing form submission logic, ensure that sensitive data is sent via POST requests rather than GET.
