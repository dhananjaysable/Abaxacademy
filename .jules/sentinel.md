## 2025-02-26 - PII Leakage via Default Form Submissions & Insecure Iframes
**Vulnerability:** React forms lacking `e.preventDefault()` on submit handlers inadvertently trigger GET requests, exposing sensitive PII (Name, Email, Mobile) in URL query parameters. Additionally, third-party iframes (e.g., Google Maps) lack strict `sandbox` policies, posing risk of pop-up abuse or unexpected top-level navigation.
**Learning:** Default form behavior in React applications without explicitly defined event handlers can quietly cause critical PII leakage to analytics, logs, and browser history. Third-party embeds must be strictly controlled even if loaded from reputable sources like Google Maps.
**Prevention:** Always enforce `onSubmit={(e) => e.preventDefault()}` for JS-handled forms to prevent unintended GET requests. Apply `sandbox="allow-scripts allow-same-origin allow-popups"` to all third-party `<iframe>` tags to balance required functionality with maximum isolation and security.
