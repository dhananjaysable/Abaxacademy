## 2024-07-18 - Prevent PII Leakage via Default Form Submissions
**Vulnerability:** Registration/contact forms without `onSubmit` handlers default to GET requests when users press enter or click submit buttons. This appends form field values (like email, names, phone numbers) directly to the URL as query parameters, leaking Personally Identifiable Information (PII) into browser history, server logs, and potential external analytics or referrers.
**Learning:** In React applications, `<form>` elements maintain their native HTML behavior. Omitting an explicit `onSubmit={(e) => e.preventDefault()}` means pressing Enter inside an input or clicking a standard submit button will trigger a page reload with GET parameters if `action` and `method` are not explicitly defined.
**Prevention:** Ensure all React `<form>` elements explicitly include an `onSubmit={(e) => e.preventDefault()}` handler to intercept standard submission and prevent unintended URL parameter serialization. Validate inputs appropriately (e.g. using `type="tel"`, `pattern`, `maxLength` for phone numbers) and handle submissions securely.
