## 2026-05-09 - Prevent PII Leakage in Forms\n**Vulnerability:** Registration forms without `onSubmit` handlers perform default GET submissions, appending form data (e.g., Name, Email, Mobile No) to the URL parameters.\n**Learning:** In a single-page React application, default form submissions are generally undesired and specifically pose a security risk when handling Personally Identifiable Information (PII) if the method defaults to GET. The risk is compounded because these URLs can be logged in browser history or server access logs.\n**Prevention:** Always add an `onSubmit={(e) => e.preventDefault()}` handler to all React `<form>` elements to intercept default submissions, and manage form data securely within component state or controlled inputs.
