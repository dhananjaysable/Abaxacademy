## 2024-05-24 - Form Input Accessibility and Validation Patterns
**Learning:** Found a pattern in this application's forms (e.g., DirectionsRegistration.jsx) where input elements rely solely on `placeholder` attributes without explicit `<label>` elements or `aria-label`s, causing issues for screen readers. Furthermore, these forms often lack basic HTML5 validation (e.g., `required`, specific `type` attributes like `tel` with patterns) and default submission prevention (`e.preventDefault()`), leading to potential unwanted page reloads or poorly validated data submissions.
**Action:** When reviewing or creating new forms in this repository, always ensure inputs have explicit `aria-label` attributes if a visible `<label>` is missing. Additionally, enforce native HTML5 validation (like `type="tel"`, `required`, `pattern`) and attach `e.preventDefault()` to `onSubmit` handlers to maintain accessible and secure client-side form behavior.
