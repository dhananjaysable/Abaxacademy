## 2025-03-24 - [Interactive Styles on Wrapper Divs]
**Learning:** Found a specific pattern in `src/components/Header.jsx` where icon-only buttons lacked `aria-label`s and had their interactive styles (e.g., hover effects) and padding applied to a non-interactive parent `<div>` wrapper instead of the semantic `<button>` element itself. This prevents keyboard users from seeing visual feedback when focusing on the button and breaks proper semantics.
**Action:** Refactored by moving all interactive styles (`hover:bg-gray-700 transition duration-300`) and padding directly to the `<button>` element, added descriptive `aria-label`s (e.g., "Facebook"), and included explicit `focus-visible:ring-2 focus-visible:ring-blue-400 focus-visible:outline-none` styles for keyboard focus visibility. Always check for this pattern when encountering icon-only buttons in the UI.
