## 2025-07-10 - Move Interactive Focus Styles from div Wrappers to Semantic buttons for Accessibility
**Learning:** In the Abax Academy application, there is a recurring pattern where interactive icon-only buttons (like social media links) lack semantic ARIA labeling and rely on `div` wrappers for interactive hover states. Applying Tailwind's `focus-visible` styles to non-semantic wrappers breaks keyboard navigation focus rings for screen reader users.
**Action:** Always refactor these components by moving the interactive styles (e.g., hover effects) directly to semantic `<button>` elements, add explicit `aria-label` attributes for icon-only components, and provide robust focus styles (`focus-visible:ring-2 focus-visible:ring-blue-500 focus-visible:outline-none`) to ensure keyboard focus is accessible.
