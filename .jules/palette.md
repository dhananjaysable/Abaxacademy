## 2024-05-24 - Accessibility Pattern: Icon-Only Buttons
**Learning:** In this application, icon-only buttons (like social media links) frequently lack `aria-label`s and have interactive styles applied to non-interactive parent `<div>` wrappers instead of the semantic `<button>` elements. This breaks keyboard accessibility because screen readers do not announce the button's purpose and keyboard focus styles are absent or visually disconnected from the actual interactive element.
**Action:** Always refactor these structures by moving interactive classes (like `hover`, `padding`, `cursor-pointer`, `border-radius`) directly to the semantic `<button>` elements. Additionally, inject `aria-label`s for screen reader support and include explicit `focus-visible` styles (e.g., `focus-visible:ring-2 focus-visible:outline-none`) to ensure keyboard navigability is visually apparent.
