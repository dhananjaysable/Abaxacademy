## 2025-06-17 - Icon-Only Button Accessibility Pattern
**Learning:** Found an accessibility anti-pattern in the application's header components where interactive styles (like `hover`, `padding`, `cursor-pointer`) and visual layout were applied to non-semantic parent `<div>` wrappers instead of the actual `<button>` elements. Furthermore, icon-only `<button>` elements were missing `aria-label`s, making them invisible to screen readers, and lacking keyboard focus indicators.
**Action:** Always verify that interactive styling and event listeners for buttons in this design system are placed directly on the `<button>` element rather than wrapping `<div>`s. Ensure that icon-only buttons receive descriptive `aria-label` attributes and include `focus-visible:ring-2 focus:outline-none` utility classes to support keyboard navigation.
