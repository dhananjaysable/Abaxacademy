## 2024-06-05 - Avoid Static Arrays in Components with Periodic State Updates
**Learning:** In components with periodic state updates (e.g., using `setInterval` to update a carousel index), defining static arrays or configuration objects inside the component function causes them to be recreated on every render. This leads to continuous and unnecessary garbage collection overhead, negatively impacting performance.
**Action:** Always move static arrays, configuration objects, and constant data outside the React component scope (or use `useMemo` if they depend on props, though hoisting is preferred for static data). When moving these, ensure to remove their properties (like `.length`) from `useEffect` dependency arrays to prevent ESLint `react-hooks/exhaustive-deps` warnings about outer scope values.
