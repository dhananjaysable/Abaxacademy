## 2024-06-21 - Extract static configuration arrays outside React components
**Learning:** In this codebase, several components (like `WhatWeDo`, `Benefits`, `CourseSection`, `CertificateSection`) define static configuration arrays (e.g., carousel items, benefit lists) inside the component body. This causes the arrays to be re-created on every render, which is particularly inefficient for components with periodic state updates (like `WhatWeDo`'s `setInterval`). Furthermore, passing these re-created arrays or their properties (like `.length`) as dependencies to hooks (like `useEffect`) can cause issues.
**Action:** Always move static arrays and configuration objects outside the React component definition and name them with uppercase letters (e.g., `CAROUSEL_ITEMS`). When doing so, remember to remove them from hook dependency arrays to avoid ESLint 'react-hooks/exhaustive-deps' warnings.
