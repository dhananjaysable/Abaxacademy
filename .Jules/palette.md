## 2024-05-15 - [Header Component Interactive Refactor]
**Learning:** Found a recurring pattern in the app's components (`Header.jsx`) where interactive UI elements (like hover effects and padding) were bound to non-interactive `<div>` wrapper tags rather than the semantic inner `<button>` elements. Additionally, `react-icons` and `lucide-react` icons inside these buttons lacked screen-reader context (`aria-label`) and visible keyboard focus states (`focus-visible:ring-2`).
**Action:** When working on navigation or header components, always consolidate layout/interactive styling directly onto semantic tags (e.g., `<button>`, `<a>`). Consistently add `focus-visible:ring-2 focus-visible:ring-blue-400 focus:outline-none` for keyboard accessibility, and ensure all icon-only buttons have descriptive `aria-label`s.
