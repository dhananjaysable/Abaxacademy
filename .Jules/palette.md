## 2024-06-05 - Icon-only buttons lacking ARIA labels and focus styles applied to wrappers
**Learning:** Found a pattern in this application's components (e.g., `Header.jsx`) where icon-only buttons lack `aria-label`s, making them inaccessible to screen readers. Furthermore, interactive styles such as hover effects and padding were applied to non-interactive parent `<div>` wrappers instead of the semantic `<button>` elements, breaking keyboard accessibility and preventing the addition of proper `focus-visible` ring styles.
**Action:** When working on UI components, specifically icon-only buttons, always refactor them by moving interactive styles and padding directly to the `<button>` element. Ensure descriptive `aria-label` attributes are added, and implement keyboard focus visibility using styles like `focus-visible:ring-2 focus-visible:outline-none`.
