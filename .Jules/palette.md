## 2024-05-20 - Forms rely heavily on visual placeholders rather than accessible labels
**Learning:** Found a widespread pattern in this application where input fields use `placeholder` text as the only form of labeling, with no explicit `<label>` or `aria-label`. This makes forms completely inaccessible to screen readers. In addition, form fields and submit buttons lacked any visual keyboard focus states (`focus-visible` or `focus:` variants). Furthermore, React forms were missing `e.preventDefault()`, which risks leaking PII via URL parameters when hitting the default GET submission action.
**Action:** When auditing or adding new components, always check that interactive elements have explicit `aria-label`s (if visible labels aren't used), add standard focus rings (e.g. `focus:ring-2 focus:ring-blue-500 focus:outline-none`), and ensure `onSubmit` handlers prevent the default action on forms.
