## 2024-06-06 - Fixing Focus Outlines on Non-Interactive Icon Wrappers
**Learning:** Applying interactive styles (like `hover:bg-gray-700`, `rounded-full`, and `cursor-pointer`) directly to non-interactive `<div>` elements that wrap semantic `<button>` elements creates an accessibility anti-pattern. This prevents users relying on keyboard navigation from seeing focus states, as the semantic button itself lacks visible styling and `focus-visible` indicators.
**Action:** When implementing icon buttons, ensure interactive styling and `focus-visible` outlines (e.g., `focus-visible:ring-2 focus-visible:ring-blue-500`) are applied directly to the semantic `<button>` element rather than wrapping `<div>` containers. Ensure all icon-only buttons have descriptive `aria-label` attributes.
